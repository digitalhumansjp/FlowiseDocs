## Flowiseとは？

Flowiseは、開発者がカスタマイズされたLLMオーケストレーションフローやAIエージェントを構築するためのオープンソースのローコードツールです。

LLMアプリの開発には、多くの反復が必要になることがよくあります。私たちのローコードとドラッグ＆ドロップUIアプローチは迅速な反復を可能にし、テストから本番環境への移行をより速く行えるようにします。
