# ツリーサマライズ

テキストチャンクとクエリが提供された場合、再帰的にツリー構造を構築し、ルートノードを結果として返します。

**長所**: 要約タスクに有効です

**短所**: ツリー構造の走査中に回答の正確性が失われる可能性があります

**プロンプト**

```
複数のソースからのコンテキスト情報は以下の通りです。
---------------------
{context}
---------------------
複数のソースからの情報のみを使用し、事前知識は使用せずにクエリに答えてください。
クエリ: {query}
回答:
```
