# チャットモデル

***

チャットモデルはメッセージのリストを入力として受け取り、モデルが生成したメッセージを出力として返します。**gpt-3.5-turbo**や**gpt4**などのこれらのモデルは、前身の**text-davincii-003**などのCompletionsモデルと比べて強力で安価です。
