# ベクトルストア

***

ベクトルストアまたはベクトルデータベースとは、高次元の数値ベクトルの保存と検索に特化したデータベースシステムの一種を指します。ベクトルストアは、これらのベクトルを効率的に管理・インデックス化し、高速な類似性検索を可能にするように設計されています。
