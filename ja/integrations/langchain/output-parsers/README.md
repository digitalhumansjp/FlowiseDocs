# アウトプットパーサー

***

アウトプットパーサーノードは、モデルの出力を受け取り、後続のタスクにより適した形式に変換する役割を担います。LLMを使用して構造化データを生成する場合や、チャットモデルやLLMからの出力を正規化する場合に便利です。

* [カスタムリストアウトプットパーサー](custom-list-output-parser.md)
* [構造化アウトプットパーサー](structured-output-parser.md)
* [高度な構造化アウトプットパーサー](advanced-structured-output-parser.md)
