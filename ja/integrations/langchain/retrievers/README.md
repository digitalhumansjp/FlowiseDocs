# リトリーバー

***

リトリーバーノードは、非構造化クエリに対してドキュメントを返します。これはベクトルストアよりも一般的な概念です。リトリーバーはドキュメントを保存する必要はなく、それらを返す(または取得する)だけで良いのです。
