# LLM

***

大規模言語モデル（略してLLM）は、大量のテキストデータで学習されたAIシステムです。これにより、幅広いプロンプトや質問に対して人間のようなテキストでコミュニケーションや生成を行うことができます。本質的に、複雑な言語を理解して応答することができます。
