# プロンプト

***

プロンプトテンプレートノードは、ユーザー入力とパラメータを言語モデルへの指示に変換するのに役立ちます。これは、モデルの応答を導き、コンテキストを理解し、関連性のある一貫した言語ベースの出力を生成するのに役立ちます。
