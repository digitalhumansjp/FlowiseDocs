# ドキュメントローダー

***

ドキュメントローダーを使用すると、PDF、TXT、CSV、Notion、Confluenceなど、さまざまなソースからドキュメントを読み込むことができます。これらは通常、[ベクトルストア](../vector-stores/)と組み合わせて埋め込みとしてアップサートされ、クエリ時に取得できるようになります。
