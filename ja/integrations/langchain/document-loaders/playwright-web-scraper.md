# Playwright ウェブスクレイパー

Playwrightは、ウェブスクレイピングのためのウェブブラウザの自動化を可能にするNode.jsライブラリです。Microsoftによって開発され、Chromiumを含む複数のブラウザをサポートしています。ウェブサイトをスクレイピングする際は、**データの倫理的かつ合法的な使用を確保するため、必ずウェブサイトの利用規約とポリシーを確認し、遵守してください**。

## 単一URLのスクレイピング

1. _(オプション)_ **[テキストスプリッター](../text-splitters/)**を接続します。
2. スクレイピングしたいURLを入力します。

## 複数URLのクロールとスクレイピング
複数ページのスクレイピングを行うには、**[ウェブクロール](../../use-cases/web-crawl.md)**ガイドを参照してください。

## 出力

URLコンテンツをドキュメントとして読み込みます。
