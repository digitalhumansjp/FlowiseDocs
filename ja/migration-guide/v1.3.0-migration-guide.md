# v1.3.0 移行ガイド

***

クレデンシャルを使用すると、すべてのサードパーティAPIキーをデータベースに保存でき、毎回コピー＆ペーストすることなく、それぞれのノードで簡単に再利用できます。

クレデンシャルは、パスフレーズを使用して作成された暗号化キーで暗号化されます。キーにアクセスできるユーザーのみがクレデンシャルを暗号化/復号化できます。さらに、ネットワークスプーフィングを防ぐため、復号化されたクレデンシャルがクライアントに送り返されることはありません。

以下は、v1.3.0への移行に役立つ重要なガイドです：

1. `PASSPHRASE`環境変数を設定します。これはクレデンシャルの暗号化/復号化に使用される暗号化キーを生成するために使用されます
2. `SECRETKEY_PATH`環境変数を設定します。暗号化キーを永続化するために、暗号化キーが保存される場所を指定します。

典型的な`.env`ファイルは以下のようになります：

```sh
PORT=3000
PASSPHRASE=MYPASSPHRASE
DATABASE_PATH=/root/.flowise
APIKEY_PATH=/root/.flowise
SECRETKEY_PATH=/root/.flowise
LOG_PATH=/root/.flowise/logs
```

3. ノードバージョン。バージョンが古い場合、ノードの右上に警告メッセージが表示されます。これはノードに新しい変更があることを意味し、メニューリストから削除して再追加する必要があります。
