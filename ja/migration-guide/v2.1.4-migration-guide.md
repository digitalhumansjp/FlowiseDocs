# v2.1.4 移行ガイド

OverrideConfigを使用すると、APIまたはEmbed使用時にフロー設定を上書きできます。セキュリティ上の懸念から、これは現在デフォルトで無効になっています。

ユーザーはUIから上書き可能な設定を明示的に指定する必要があります。

1.) 設定に移動：

<figure><img src="../.gitbook/assets/image (189).png" alt="" width="221"><figcaption></figcaption></figure>

2.) 設定の上書きを有効化：

<figure><img src="../.gitbook/assets/image (190).png" alt=""><figcaption></figcaption></figure>

3.) 上書き可能な設定のトグルをオンにして保存します。

<figure><img src="../.gitbook/assets/image (191).png" alt=""><figcaption></figcaption></figure>

4.) 例えば、ユーザーは以下のような変数と設定を上書きできます。[OverrideConfig](../using-flowise/api.md#override-config)を参照してください。

```json
{
    "overrideConfig": {
        "systemMessage": "You are helpful assistant",
        "vars": {
            "character": "nice"
        }
    }
}
```
